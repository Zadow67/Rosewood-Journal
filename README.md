# Rosewood Journal

Rosewood Journal is a journal and productivity app I made to keep my thoughts, tasks and habits organised in one place. It has a simple interface with a few useful features for everyday use.

## Features

- Write and save journal entries
- Keep track of daily tasks and habits
- Set reminders and priorities
- Track your mood and write monthly reflections
- Search entries and mark favorites
- Dark mode and custom accent colors
- Export and import backups
- Export data as CSV and print entries

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start writing and organising your day.

## Built With

- HTML
- CSS
- JavaScript

## Data Storage

Your data is saved locally in your browser, so it stays on your device. Make sure to export a backup if you want to keep a copy of your entries.
